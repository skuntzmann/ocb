Installation sur Android

Vous pouvez installer OCB sur l'écran d'accueil de votre téléphone.

Si l'installation automatique n'est pas proposée :

  1. Appuyez sur le menu ⋮ de Chrome.
  2. Choisissez Ajouter à l'écran d'accueil ou Installer l'application.
  3. Confirmez l'installation.
Installation sur iPhone / iPad

🌐 Ouvrez cette page dans Safari.

  1. Appuyez sur le bouton Partager 📤.
  2. Choisissez Sur l'écran d'accueil.
  3. Appuyez sur Ajouter.
Installation sur ordinateur

Si votre navigateur propose l'installation du site, utilisez l'icône d'installation dans la barre d'adresse ou le menu du navigateur.
