Installer OCB

Vous utilisez actuellement un navigateur autre que Chrome.

Pour installer OCB sur l'écran d'accueil de votre téléphone, ouvrez cette page avec Google Chrome.

🌐 Ouvrir dans Chrome Si le bouton ne fonctionne pas, ouvrez cette adresse avec Chrome :
skuntzmann.github.io/ocb/
Installer OCB

Ajoutez OCB à l'écran d'accueil de votre téléphone.

Si l'installation automatique n'est pas proposée :

  1. Appuyez sur le menu ⋮ de Chrome.
  2. Choisissez Ajouter à l'écran d'accueil ou Installer l'application.
  3. Confirmez l'installation.
Installer OCB

Pour installer OCB sur votre iPhone ou votre iPad :

  1. Ouvrez cette page dans Safari.
  2. Appuyez sur le bouton Partager 📤.
  3. Choisissez Sur l'écran d'accueil.
  4. Appuyez sur Ajouter.
Installer OCB

Vous pouvez installer OCB sur votre ordinateur si votre navigateur propose cette fonction.

Recherchez l'icône d'installation dans la barre d'adresse ou dans le menu de votre navigateur.
