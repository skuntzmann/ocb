OCB — mini web-app installable

Cette version ouvre directement le Digipad :
https://digipad.app/p/1234419/95149a1460b23

IMPORTANT :
Pour que l'installation PWA fonctionne, ces fichiers doivent être hébergés sur un site en HTTPS.

ANDROID :
Ouvrir l'adresse de la page dans Chrome puis choisir Installer / Ajouter à l'écran d'accueil.

IPHONE/IPAD :
Ouvrir la page dans Safari > Partager > Sur l'écran d'accueil.

Le mode protégé et le mot de passe sont gérés par Digipad. Cette mini-app ne stocke pas elle-même le mot de passe.
